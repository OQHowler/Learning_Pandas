# 📊 Learning Pandas (Hands-on Data Analysis Repository)

## 🚀 Overview

This repository documents my **practical, code-first approach to learning
Pandas** for data analysis and manipulation.



------------------------------------------------------------------------

## 📂 Repository Structure

The files are organized to build understanding step-by-step:

1.  **SERIES.py**\
    → Introduction to Pandas Series

2.  **DataFrame.py**\
    → Creating and manipulating DataFrames

3.  **Working_With_Data.py**\
    → Loading and exploring datasets

4.  **Data_Cleaning.py**\
    → Handling missing values and cleaning data

5.  **Aggregate_Functions.py**\
    → Grouping, aggregation, and statistics

6.  **poke_data.csv**\
    → Sample dataset used for practice

------------------------------------------------------------------------

## 🧠 Learning Approach

-   Focused on **learning by doing**
-   Each file covers a **single concept clearly**
-   Progression from **basics → applied data handling**
-   Emphasis on understanding **real-world data workflows**

------------------------------------------------------------------------

## ⚙️ How to Use

Run scripts in order:

``` bash
python SERIES.py
```

Follow the sequence listed above for best learning progression.
